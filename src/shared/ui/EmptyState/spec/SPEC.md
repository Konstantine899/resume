# SPEC — shared/ui/EmptyState

> Единственная истина для этого компонента (spec-driven workflow: AGENTS.md, раздел Spec-driven features). Статусы: `draft` → `approved` → `done`.
> Фаза A создана вручную из `scripts/createSlices/templates/spec.mjs` (нет `shared` в `generatorLayers`); фаза B выполняется вручную. Исходный план: vault `wiki/plan/plan_kit_empty_state.md`, рев.1.

## Цель

Объединить пять разных пустых состояний, найденных аудитом (4× `Paragraph muted` + голый `<p>` на дашборде, `DashboardPage.tsx:29`), за одним презентационным компонентом, чтобы каждый пустой список получил единую форму из title/description/CTA.

## Контекст

- Слой: `shared` (FSD), компонент: `ui/EmptyState`; Redux: нет; зависимости: kit `Paragraph`, kit `Button` (композиция, план A3).
- Доказательства: локальные ключи `skillsListEmpty`, `adminJobsEmpty`, `workHistoryEmpty`, `adminDashboardEmpty`, `skillsEmpty` — у каждого своя формулировка и своё наличие CTA; условные рендеры разбросаны по `MyWork.tsx`, `SkillsInner.tsx`, `WorkHistory.tsx`, `DashboardPage.tsx` и трём админ-спискам.
- **Ни одной строки внутри kit** (план A2): title/description/action — это `ReactNode`, которые передаёт потребитель через `t()`; локальные ключи остаются во владении фич, компонент не импортирует i18n-конфиг.
- Рекомендуется до пилота DataTable, чтобы его слот `emptyState` мог принять компонент напрямую (мягкая последовательность, не блокер — слот это `ReactNode`).

## Критерии приёмки

- [ ] Рендерит только `title`, если передано лишь оно.
- [ ] Рендерит `title` + `description`, когда переданы оба.
- [ ] Рендерит слот `action` и пересылает клики обработчику потребителя (компонент не владеет логикой кликов).
- [ ] Пропсы `compact` и `align` отображаются на CSS-модификаторы; сторисы показывают оба варианта.
- [ ] Незаданные опциональные слоты (`description`, `action`) не создают пустых обёрток в DOM.
- [ ] Компонент не добавляет собственного текста — при всех пропсах-фикстурах отрендеренный текст точно равен входному (тест на отсутствие захардкоженных строк).
- [ ] Сторисы рендерят фикстурные строки en и ru, обе темы, 390px.
- [ ] Пилот (OPEN-1): голый `<p>` на дашборде (`adminDashboardEmpty`) и пустое состояние админ Skills (`skillsListEmpty`) рендерятся через компонент **с неизменёнными локальными ключами** (без переименований ключей, для самого переиспользования новые ключи не нужны).
- [ ] Пилот: axe `/admin` → 0 новых нарушений; `check:bundle` в пределах лимитов.
- [ ] Запись добавлена в `wiki/ui-kit/components-list.md`.

## Что не входит

- Иллюстративные иконки (план OPEN-2 — только текст и CTA; иконки без доказанной пользы — визуальный шум).
- Анимации, иллюстрации или варианты пустых состояний «onboarding».
- Перенос локальных ключей в kit (план A2 это запрещает — фичи сохраняют владение строками).

## Риски

- Дрейф владения ключами: если кто-то потом «с благими намерениями» перенесёт `skillsListEmpty` и т.п. в общий i18n, сломаются тесты паритета и владение фич — A2 это страж.
- Ползучесть области в сторону виджета с иконками и анимацией (план §7) — A4 сохраняет примитив примитивом.
