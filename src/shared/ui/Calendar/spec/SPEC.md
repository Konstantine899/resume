# SPEC — shared/ui/Calendar + shared/ui/DatePicker

> Единственная истина для этих компонентов (spec-driven workflow: AGENTS.md, раздел Spec-driven features). Статусы: `draft` → `approved` → `done`.
> Фаза A создана вручную из `scripts/createSlices/templates/spec.mjs` (нет `shared` в `generatorLayers`); фаза B выполняется вручную. Исходный план: vault `wiki/plan/plan_kit_calendar.md`, рев.5. Два компонента — один атомарный план.

## Цель

Заменить нативный `<input type="date">` на выбор даты с темой по токенам, i18n и клавиатурной доступностью: нативный инпут игнорирует переключатель языка приложения, выглядит по-разному в разных браузерах и лежит вне токенов тёмной темы. Пилот выполнен (WU-4): оба date-инпута `JobForm.tsx` теперь рендерят kit DatePicker.

## Контекст

- Слой: `shared` (FSD), компоненты: `ui/Calendar` (ARIA APG date-grid) + `ui/DatePicker` (kit `Input` + kit `Popover` + Calendar); Redux: нет; зависимости: kit `Input`, `Popover`, `Button`, `Icon`.
- Интеграция с формой: RHF `Controller` (составной контрол — `register` не может им управлять); значение на границе формы остаётся ISO `yyyy-mm-dd` (план A2); zod-схема не меняется.
- **Правило часовых поясов (план A7, рев.3):** внутри компонентов дата — СТРОКА: год/месяц/день парсятся из ISO-строки, никогда из `new Date(iso)` (полночь UTC сдвигает отображаемый день на −1 в отрицательных поясах). Единственное преобразование строка→Date в приложении — `z.coerce.date()` в `src/entities/Job/model/schemes/schema.ts` (комментарий A11); пилот его не меняет (проверено: 0 вызовов `new Date(` в JobForm/jobsSlice/Job utils).

## Критерии приёмки

- [ ] Сетка календаря следует ARIA APG: ArrowLeft/Right (день), ArrowUp/Down (неделя), PageUp/PageDown (месяц), Home/End (начало/конец недели), скользящий tabindex, `role="grid"` с ячейками дней, отдающими `aria-selected`.
- [ ] Клавиатурная навигация, пересекающая границу месяца, перерендеривает новый месяц; отключённые дни (`minDate`/`maxDate`) нельзя выбрать ни с клавиатуры, ни кликом.
- [ ] `value: null` → рендерит текущий месяц без выбранного дня.
- [ ] Утилита ISO-парсера возвращает корректные год/месяц/день для `2025-12-31`, `2026-01-01`, `2028-02-29` БЕЗ создания объекта `Date` (защита от сдвига часового пояса, план A7).
- [ ] DatePicker рендерит kit `Input` + календарь в поповере + кнопку очистки; некорректный ручной ввод подсвечивает поле и никогда не бросает исключение.
- [ ] Ручной ввод принимает тот же формат, что и отображается (рекомендация плана OPEN-4: отображение `dd.mm.yyyy`, значение ISO; парсер принимает оба) — один парсер живёт в `DatePicker/lib/`, больше нигде не используется.
- [ ] Тест интеграции с RHF `Controller`: значение до и после выбора даты ходит туда-обратно как ISO; проп `disabled` блокирует и инпут, и поповер.
- [ ] Строки месяцев/дней/aria и `firstDayOfWeek` управляются i18n (понедельник для ru, воскресенье для en) с тестом паритета en+ru.
- [ ] Пилот (OPEN-2): оба date-инпута JobForm становятся DatePicker; логика A6 (current ⇒ endDate отключается и очищается) и привязка `minDate`/`maxDate` ведут себя идентично; существующие тесты JobForm проходят с правками только селекторов; storage и витрина не трогаются (тот же ISO в DTO).
- [ ] Пилот: axe `/admin/jobs` → 0 новых нарушений (маршрут в `PATHS`); `check:bundle` в пределах лимитов.
- [ ] Сторисы: обе темы, ограничения min/max, выбранная/пустая дата, вьюпорт 390px.
- [ ] Drill-down (WU-5, одобрен владельцем как «Вариант 2»): три вида — дни → месяцы → декада; шапка-кнопка поднимает уровень («June 2026» → «2026» → «2020–2029», дефис en-dash), в декаде шапка не интерактивна (верхний уровень).
- [ ] WU-5: месяцы/годы — нативные `<button>` (Tab/Enter бесплатно); выбор месяца возвращает дни этого месяца (фокус — на roving-ячейку), выбор года открывает месяцы этого года с сохранённым месяцем (фокус — на кнопке текущего месяца).
- [ ] WU-5: chevron-стрелки зависят от вида: дни ±1 месяц, месяцы ±1 год, декада ±10 лет; min/max: месяц/год `aria-disabled`, если ВНУТРИ него нет ни одного доступного дня (навигация не блокируется — клик-guard как у дней).
- [ ] WU-5: навигационные клики (chevron, шапка, кнопка месяца/года) НЕ всплывают — поповер DatePicker остаётся открытым (предсуществующий баг «chevron закрывает поповер» исправлен); выбор дня всплывает и закрывает поповер (контракт не меняется).

## Что не входит

- Выбор диапазона дат и времени (план OPEN-1 — сложность сетки ×2, в резюме нет данных о диапазонах).
- Сохранение значения в локализованном формате (значение остаётся ISO; форматирование только для отображения).
- Тач-специфичные колёсные пикиры и нативный mobile UI для дат.

## Риски

- ARIA date-grid — самая тяжёлая a11y-поверхность в серии; в WU-1 пропорционально больше тестов; объявления SR проверяются вручную.
- Расположение поповера у нижнего края вьюпорта — перепроверить `calculatePosition` на 390px.
- Ползучее дублирование парсера: ровно один парсер (`DatePicker/lib/isoDate.ts`); если Calendar нужны части — он его импортирует; второй парсер где угодно — блокер ревью.
