# SPEC — features/MyWork

> Единственная истина для этой фичи (spec-driven workflow: AGENTS.md, раздел Spec-driven features). Статусы: `draft` → `approved` → `done`.
> Исходный план: vault `wiki/plan/plan_mywork_pagination.md`, рев.1. Критерии живут ТОЛЬКО здесь; рабочие единицы — в [TODO.md](./TODO.md); решения и контекст — в плане vault.

## Цель

Пагинация showcase-блока «Мои проекты» + выбор количества отображаемых элементов (5 / 10 / 20), чтобы блок выдерживал рост до сотен проектов. Решение владельца (2026-10-08): список — **ВСЕ проекты**, не только featured. Ревизия владельца (2026-10-09): размеры 5 / 10 / **20** (50 заменён на 20).

## Контекст

- Слой: `features/MyWork` (не kit). Контрол размера страницы **не** становится kit-компонентом — решение дискуссии 2026-10-08: сегодня один потребитель, шов не заводим («один адаптер — гипотетический»).
- Design C сохраняется: данные приходят пропсом `content` из `HomePage` (store), seed-fallback — в компоненте. Состояние вида (`page`, `pageSize`) — локальный `useState` в `MyWork`: не store, не URL.
- kit `Pagination` используется как есть, его SPEC не меняется — `pageSize` снаружи ровно по его OPEN-2 («состояние остаётся снаружи»).
- Данные: сид — 7 проектов (4 featured). Сегодня видно 4 → контролы скрыты (`totalPages <= 1`). После изменения — все 7 при `pageSize=5` → сразу 2 страницы: **витрина визуально меняется в этом же PR** (ожидаемо, скриншот в PR).

## Критерии приёмки

- [ ] `HomePage` передаёт в `MyWork` все проекты (`selectAllProjects`), а не featured: тест wiring обновлён, на витрине видны все 7 заголовков сида.
- [ ] Fallback без store: `content ?? PROJECTS` — все 7, не featured-подмножество; `getFeaturedProjects` больше не импортируется из `MyWork.tsx`.
- [ ] `pageSize` по умолчанию = 5.
- [ ] Проектов ≤ `pageSize` → **не видны ни пагинация, ни группа размера** (оба контрола показываются только при `totalPages > 1`).
- [ ] 7 проектов при `pageSize=5` → страница 1 активна, ровно 5 карточек; клик по «2» → ровно 2 карточки, страница 2 активна.
- [ ] Группа размера: `role="group"` + `aria-label` из i18n; активная кнопка `aria-pressed="true"`, остальные `aria-pressed="false"`; значения — ровно 5, 10, 20 (кнопки «50» нет).
- [ ] Раскладка (владелец 2026-10-09): группа размера — **под заголовком «Мои Работы», над сеткой, прижата вправо**; навигация пагинации — **внизу, по центру** (оба блока по-прежнему видны только при `totalPages > 1`).
- [ ] Клик по размеру → новый `pageSize` И `page` сбрасывается на 1: находясь на странице 2 (`pageSize=5`), выбор «10» → все 7 карточек на одной странице (без сброса была бы пустая страница).
- [ ] Порядок карточек = порядок данных (store/сида); флаг `featured` на видимость и порядок витрины не влияет.
- [ ] i18n: один новый ключ (aria-label группы) есть в `en.json` и `ru.json`, тест паритета зелёный; захардкоженных строк в UI нет (числа 5/10/20 — не текст).
- [ ] Тесты зелёные: `MyWork.test` (окно строк, скрытие контролей, сброс страницы, пустое состояние), `HomePage.test` (wiring на `selectAllProjects`, все заголовки).
- [ ] Гейты: `npm run validate`; `check:bundle` в лимитах (Pagination уезжает в main-чанк — дельта записана); axe `/` — 0 новых нарушений (маршрут в PATHS уже есть).

## Что не входит

- Новый kit-компонент «PageSize/Select» — вердикт дискуссии 2026-10-08: один потребитель; появление второго = вынос в kit отдельным рефактором (без ломки потребителя).
- Изменения kit `Pagination` (его SPEC/пара из PR #189 не трогаются).
- URL-state (`?page=`) — deep-links как экосистема (аудит P0), отдельный шаг.
- Судьба флага `featured` и селектора `selectFeaturedProjects` (OPEN-1) — в этом PR не удаляем.
- Виртуализация — defer с порогом (дискуссия 2026-10-08: включать при измеренном N ≥ 500–1000 и непрерывном скролле как продуктовом требовании).
- Админ-списки / DataTable.

## Риски

- `HomePage.test.tsx` (wiring featured + ассерты заголовков) и `MyWork.test.tsx` (использует `getFeaturedProjects`) ломаются **ожидаемо** — обновляем контракт, не заменяем ассерты моком.
- Витрина меняется немедленно (7 проектов → 2 страницы) — не «скрытая фича»: владелец должен увидеть до/после в PR.
- main-чанк растёт на размер kit `Pagination` — headroom серии ~28 KiB, ожидаемо влезает, но замер обязателен.
