# Multi-Agent MCP Server Integration - Контекст

## 🎯 Цель интеграции

**Главная цель:** Интегрировать готовый Multi-Agent MCP Server (Node.js) в проект Resume для автоматической оркестрации AI агентов через Continue IDE.

**Ключевые задачи:**

- Настройка и подключение готового @multi-agent/mcp пакета
- Конфигурация взаимодействия с Continue через MCP protocol
- Адаптация существующих агентов проекта под оркестратор
- Тестирование и валидация работы системы

## 🏗️ Архитектура интеграции

### Компоненты системы:

1. **Multi-Agent MCP Server** - Готовый Node.js оркестратор (@multi-agent/mcp)
2. **Continue IDE** - Основная среда разработки с MCP client
3. **Existing Agents** - Существующие агенты проекта (адаптированные)
4. **Project Codebase** - Кодовая база Resume для анализа

### Стек технологий:

- **Node.js 18+** - Для запуска MCP сервера
- **MCP Protocol** - Для коммуникации с Continue
- **Existing Python Agents** - Адаптация под оркестратор
- **Ollama Models** - Локальные AI модели

## 🔌 Точки интеграции

### Внутренние интеграции:

- **Continue IDE** ← MCP Protocol → **Multi-Agent MCP Server**
- **MCP Server** → **Existing Python Agents** (через адаптеры)
- **MCP Server** → **Ollama Models** (локальные модели)
- **MCP Server** → **Project File System** (анализ кода)

### Конфигурационные файлы:

```yaml
# .continue/mcpServers/multi-agent-mcp.yaml
name: 'multi-agent-mcp'
command: 'npx'
args: ['-y', '@multi-agent/mcp']
env:
  MCP_PORT: 8000
  PROJECT_ROOT: 'D:/Dev/projects/resume'
```
