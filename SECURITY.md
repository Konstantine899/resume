# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported.

| Version | Supported |
| ------- | --------- |
| main    | yes       |

## Reporting a Vulnerability

Please report security issues **privately**:

- Open a [GitHub Security Advisory](https://github.com/Konstantine899/resume/security/advisories/new), or
- Contact the maintainer directly (see profile).

Do **not** open public issues for vulnerabilities. You will receive an acknowledgement and a plan for a fix.
