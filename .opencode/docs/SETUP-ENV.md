# 🔐 Настройка переменной окружения CONTEXT7_API_KEY

## Windows PowerShell (от имени администратора)

```powershell
[System.Environment]::SetEnvironmentVariable('CONTEXT7_API_KEY', 'ctx7sk-5885363f-cc51-420b-9657-2ab63bba8558', 'User')
```

## Проверка установки

```powershell
echo $env:CONTEXT7_API_KEY
```

Должно вывести: `ctx7sk-5885363f-cc51-420b-9657-2ab63bba8558`

## Альтернативный способ (через GUI)

1. Нажмите `Win + R`
2. Введите `sysdm.cpl`
3. Вкладка "Дополнительно" → "Переменные среды"
4. В разделе "Переменные среды пользователя" нажмите "Создать"
5. Имя: `CONTEXT7_API_KEY`
6. Значение: `ctx7sk-5885363f-cc51-420b-9657-2ab63bba8558`
7. Нажмите OK

## После установки
